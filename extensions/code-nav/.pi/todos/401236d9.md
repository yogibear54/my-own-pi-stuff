Phase 2 complete. Changes:

**`src/config.ts`**
- Added `FetchContextConfig` interface with 6 fields
- Added `DEFAULT_FETCH_CONTEXT` defaults
- `resolveToolsConfig()` now resolves `fetchContext` section from `raw.fetchContext`

**`src/engine.ts`**
- Added exported `FetchContextConfig` interface (re-declared for engine consumers, mirrors config.ts)
- `fetchContext()` now accepts optional `config?: FetchContextConfig` parameter
- Defaults resolved from config instead of hardcoded: `before` (was 5), `after` (was 5), `maxLines` (was 100), `maxLinesCap` (was 200)
- `buildContainerResult()` accepts config; uses `containerDeclMaxLines` (was hardcoded 10) and `signatureDisplayLength` (was hardcoded 80)

**`src/tools.ts`**
- `code_nav_fetch_context` passes `config.fetchContext` to `fetchContext()`

**`index.ts`**
- `/code-nav-config` command now shows fetchContext settings
