Populate the edges table to track cross-file relationships (imports, calls, inherits) for better reference resolution.

**Implementation plan:**
1. Update store.ts schema to add edges table:
   ```sql
   CREATE TABLE edges (
     id INTEGER PRIMARY KEY,
     source_file TEXT NOT NULL,
     source_symbol TEXT NOT NULL,
     target_file TEXT,
     target_symbol TEXT,
     relationship TEXT NOT NULL  -- 'imports', 'calls', 'inherits', 'extends'
   );
   CREATE INDEX idx_edges_source ON edges(source_file, source_symbol);
   CREATE INDEX idx_edges_target ON edges(target_symbol);
   ```
2. Update indexer.ts to extract import statements using Tree-sitter queries
3. Update engine.ts to use edges for smarter reference filtering
4. Add `findCallees()`, `findImportSources()` helper functions

**Success criteria:**
- Imports tracked per file
- Reference search filters by import relationships
- Handles re-exports (export { foo } from './bar')
