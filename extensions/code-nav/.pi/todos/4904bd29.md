Phase 4 complete. Changes:

**`src/config.ts`**
- Added `LanguagesConfig` interface with `enabled: string[]` field
- Added `ALL_LANGUAGE_NAMES` constant for validation
- Added `resolveLanguagesConfig()` — validates language names, falls back to all if empty/invalid
- `CodeNavToolsConfig` now includes `languages` section

**`src/languages/registry.ts`**
- Added `setEnabledLanguages()` — stores a filter set (null = all enabled) affecting `getSupportedExtensions()`
- `getSupportedExtensions()` now filters by enabled languages (used by `fullIndex` file walking)
- `initParser()` accepts optional `enabledLangs?: string[]` — only loads WASM grammars for enabled languages
- `detectLanguage()` unchanged — still works for any registered language

**`index.ts`**
- Imports `setEnabledLanguages` from registry
- Calls `setEnabledLanguages()` before `initParser()` in session_start
- Passes `toolsConfig.languages.enabled` to `initParser()`
- `/code-nav-config` shows languages section

**SETTINGS.md**
- Marked `languages` as ✅ Implemented
