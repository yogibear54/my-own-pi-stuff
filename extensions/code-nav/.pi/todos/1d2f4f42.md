Implement a file system watcher to keep the index fresh without requiring full re-indexes.

**Implementation plan:**
1. Create watcher.ts module using Node.js fs.watch or chokidar
2. Debounce rapid file changes (e.g., 300ms)
3. On file change:
   - Re-parse the changed file with indexer.ts
   - Update SQLite store
4. Register with pi.on('session_start') lifecycle

**Success criteria:**
- Detects file adds, changes, deletes
- Re-indexes changed files automatically
- Cleans up deleted files from index
- Debounces bulk operations (e.g., git checkout)
