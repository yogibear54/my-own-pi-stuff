Phase 3 complete. Changes:

**`src/config.ts`**
- Added `DatabaseConfig` interface with 3 fields: `journalMode`, `synchronous`, `cacheSizeMB`
- Added `DEFAULT_DATABASE` defaults and validation sets (`VALID_JOURNAL_MODES`, `VALID_SYNCHRONOUS`)
- Added `resolveDatabaseConfig()` — validates pragma values against allowed sets, falls back to defaults for invalid values
- `resolveToolsConfig()` now includes `database` section

**`src/store.ts`**
- Added exported `DatabaseConfig` interface
- `Store` constructor accepts optional `dbConfig?: DatabaseConfig` parameter
- Pragma values applied from config instead of hardcoded strings
- `cache_size` computed from `cacheSizeMB * 1000` (SQLite uses negative KB values for cache)

**`index.ts`**
- Both `new Store()` calls now pass `toolsConfig.database` from resolved config
- `toolsConfig` resolved once before store construction (reused for `setMeta`)
- `/code-nav-config` command displays database settings
