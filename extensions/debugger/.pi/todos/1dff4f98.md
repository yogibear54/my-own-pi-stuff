Verified (11 state assertions + 14 integration):
- 7-state machine (AWAITING CONTEXT / AMBIGUOUS / PARSING ASSET / HYPOTHESIS & BUG VALIDATION / FIXING BUG / BUG FIXED / DEBUG SUMMARY).
- `reportHypothesis` increments hypothesisCount; `recordContinue` increments attempts and at maxAttempts (default 3, configurable) falls back to AWAITING CONTEXT and resets attempts.
- Snippet tracking add/remove/get; subscribe + subscribeAndEmit; serialization round-trip + tolerant `fromSerialized` (bad enum → AwaitingContext).
- Tools: report_hypothesis / request_user_test (ui.select verdict) / mark_bug_fixed (cleanup telemetry, keep fix, final validate) / debug_summary (exit vs continue).
- Skill contributed via resources_discover; `before_agent_start` injects current state+goal+target as display:false context while active.
- Integration: full hypothesis→fix→"Bug Fixed"→mark_bug_fixed→debug_summary→exit flow drives persisted state through the real tool calls.

Resolved open items: maxAttempts is a session option (default 3); final validation = `mark_bug_fixed` prompts the user once more after telemetry removal, reverting to hypothesis/context on regression.
