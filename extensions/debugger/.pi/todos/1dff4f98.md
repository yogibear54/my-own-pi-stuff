## Decisions (from the plan Q&A)
- **Loop guidance**: `before_agent_start` phase injection (every turn) + tool `promptGuidelines`. **No `SKILL.md`** — pi has no extension skill API.
- **Snippet tracking**: `state.ts` owns the persisted map; `tools.ts` reads/writes through it (single source of truth, resume-safe).
- **Transitions are tool-driven** (inside `execute`), not `turn_end` introspection.
- **`request_user_test` folds** `record_test_result` + `mark_bug_fixed` (one user-gated tool).
- **Final validation** = user-gated manual confirm in `debug_summary` (no auto re-injection).
- **`maxAttempts`** = `DEFAULT_MAX_ATTEMPTS` (3) constant in `state.ts`.

## Acceptance criteria — verified by `state.test.mjs` + `snippets.tools.test.mjs`
1. ✅ `/debugger` → `AWAITING CONTEXT`.
2. ⚠️ Stack-trace→hypothesis: works (model calls `report_hypothesis` directly); `AWAITING CONTEXT: AMBIGUOUS` / `PARSING ASSET` defined but not auto-driven (Phase 1 heuristics = future).

7. ✅ Model kept phase-aware via `before_agent_start` injection + tool prompts.
