Custom tools for delimited telemetry snippets. **Reference: [docs/04-snippet-injection-cleanup.md](docs/04-snippet-injection-cleanup.md).**

Scope:
- Delimiters: `/* AI_DEBUG_SNIPPET_START:ID=<n> NAME="..." */ ... /* AI_DEBUG_SNIPPET_END */` (block style); line-comment style for Python/Ruby/Shell.
- Tools (active only in debug mode), all using `withFileMutationQueue(absPath)` and normalizing leading `@`:
  - `inject_snippet(path, line, id, name, language, code)`
  - `remove_snippet(path, id)` / `{all:true}`
  - `list_snippets(path?)`
  - `cleanup_all_snippets()` (called by `/debugger stop` and on fix acceptance; fixes ≠ snippets)
- Snippet body POSTs a schema-valid packet to the session telemetry target.
- Register `promptSnippet` + `promptGuidelines` so the model always uses delimiters + correct target.
- Track `{ id → { file, name, line } }` per session; persist via Part 5 so `/resume` can clean up.

Acceptance criteria: see doc §Acceptance Criteria (incl. concurrency vs built-in edit, byte-identical cleanup except accepted fix).
