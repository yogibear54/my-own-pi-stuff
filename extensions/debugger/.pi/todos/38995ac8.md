Skeleton DONE + tested (8 widget assertions). Integrated in `index.ts` via `ctx.ui.setWidget("debugger", (tui, theme) => ({ render, invalidate }))`, reading live state on each render and re-rendering on change via `tui.requestRender()` (throttled). Renders [] (hidden) when inactive.

Implemented all 4 regions across all 7 states:
- Header: state label (colour-coded), LIVE LOGGING tag (when packet <5s old), `:port mode`, telemetry target.
- Hypothesis: statement + #counter + (attempts/max) + files.
- Log stream: level-coloured pretty packets, tail-capped.
- Body: state-appropriate prompt (incl. the "Bug Fixed / Continue to Debug" affordance text in FIXING BUG).
