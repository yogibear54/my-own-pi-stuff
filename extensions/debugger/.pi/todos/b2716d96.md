Build the HTTP log server as a **standalone module**. **Reference: [docs/01-log-server.md](docs/01-log-server.md).**

## Scope (Part 1 = module only)

Create `server.ts` exporting `startLogServer(opts)` → handle. Do **not** touch `index.ts` or `widget.ts` (lifecycle wiring + widget feed are later parts). Verify standalone.

## Handle

`{ port, logFile, telemetryTarget, close(), onPacket(cb) }`

- `port`: actual bound port (may differ from requested after auto-increment).
- `logFile`: absolute session JSONL path.
- `telemetryTarget`: `http://localhost:<port>`.
- `close()`: stop listener, drop ring buffer, close log handle. Idempotent.
- `onPacket(cb)`: single callback, invoked synchronously per validated packet.

## Options

`port?` (explicit, highest precedence); `cwd?` (default `process.cwd()`); `bufferSize?` (default 500).

## Port resolution

First defined wins: `opts.port` > `PI_DEBUGGER_PORT` > `debugger.port` (settings) > `DEFAULT_PORT` (8866).

- Settings = global `getSettingsPath()` overlaid by project-local `<cwd>/<CONFIG_DIR_NAME>/settings.json` (project wins).
- On `EADDRINUSE`, auto-increment from the effective port until free (ceiling 65535); report the bound port.

## Endpoint behavior

| Case | Response |
|---|---|
| valid+schema | `200 {"status":"success"}` |
| malformed (unparseable) JSON | `400` |
| valid JSON not matching schema | `400` |
| non-POST | `405` (`Allow: POST`) |

## Validation (400 if missing/wrong-typed)

`log_id:string`, `event_timestamp:string`, `level:string` (**non-empty; no enum**), `source:{file:string,line:number,function:string}`, `message:string`; optional `variables?:object`, `stack_trace?:string`.

## Log file

One per `startLogServer` call under `<cwd>/<CONFIG_DIR_NAME>/logs/`. Use SDK `CONFIG_DIR_NAME` (not hardcoded `.pi`); `mkdir -p`. Filename = 8 alphanumerics + `.log` (`crypto.randomBytes`, base36, len 8). Append `JSON.stringify(packet)+"\n"` per validated packet.

## Ring buffer

Last N (default 500) packets + monotonic seq counter; feed via `onPacket`.

## Verification

Commit a node test script asserting 200/400/405, append-to-same-file on repeat POSTs, dir auto-create (run as verify step); keep curl commands from doc §Acceptance Criteria documented.

## Out of scope (later parts)

`index.ts` lifecycle wiring (start on `/debugger`; stop on `/debugger stop` + `session_shutdown`), widget `logLines` feed, ngrok/remote, snippet injection, debugging loop.

## Decisions baked in

- **Scope:** module-only (`server.ts`); no `index.ts`/`widget.ts` changes.
- **`level`:** non-empty string; no enum.
- **Port conflict:** auto-increment from effective port (incl. explicit sources) up to 65535.
- **Port config:** wired — env `PI_DEBUGGER_PORT` + settings key `debugger.port`; precedence `opt > env > settings > default`.
- **cwd/settings:** `opts.cwd` (default `process.cwd()`); global overlaid by project-local (project wins).
- **Verification:** committed test script + documented curl.
- **Naming:** env `PI_DEBUGGER_PORT`; settings key `debugger.port`.
