Done. `server.ts` (dependency-free, node built-ins only) + isolated smoke test (`scripts/smoke-test.ts`, run via `node --experimental-strip-types`).

Verified acceptance criteria (all passing):
- POST valid → 200 `{"status":"success"}`
- malformed JSON → 400
- schema-invalid → 400
- GET → 405 with `Allow: POST`
- second valid POST appends as a new JSONL line to the SAME per-session file
- onPacket fires for valid packets only
- close() idempotent; afterwards connection refused
- missing nested logs dir auto-created

Design: caller passes `logsDir` (computed by index.ts via CONFIG_DIR_NAME) so server.ts stays decoupled from pi and is independently testable. `isValidPacket` exported for reuse. Port default 8866; supports port 0 (OS-assigned) for tests.
